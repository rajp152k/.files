# Neovim configuration guidance

Before changing this Neovim configuration, read `lua/do-not-ignore.lua` in full. It records the user's workflow, navigation-key contracts, and why Mason remains in the setup. This file and the Lua guidance are versioned in `~/.files/nvim` and deployed through GNU Stow.

When changing bindings, update `~/nvim.ref.md` as well. Do not treat the presence of only Java, Go, or Flutter in a current project as permission to remove the other language servers.
